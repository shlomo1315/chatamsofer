# המערכת הטלפונית — אפיון ובנייה מחדש

**תאריך:** 31.08.2026 · **סטטוס:** לאישור

---

## 1. מה לא עובד היום

**המידע מפוזר על פני 7 מסכים** שאין ביניהם קשר:
`PhoneSystemPanel` · `IvrBuilder` · `YemotMainMenuSettings` · `YemotHolidaySettings` ·
`YemotMaternitySettings` · `YemotCallLog` · `ElevenLabsStudio`

וכולם קבורים בתוך **הגדרות** — מקום שנכנסים אליו פעם בחודש, בזמן שהמערכת הטלפונית
היא ערוץ מרכזי שדרכו נרשמות אלפי משפחות.

| הבעיה | מה זה עושה בפועל |
|---|---|
| אין מסך אחד | כדי לשנות הודעה צריך לדעת מראש באיזה מסך היא |
| הקלטה במקום אחר | עורכים טקסט כאן, מקליטים שם, מחברים ידנית |
| אין האזנה | שולחים לאלפי מתקשרים בלי לשמוע |
| 4 כתובות webhook | כל שינוי דורש נגיעה גם בימות |
| סימולטור חלקי | קיים רק למוקדי חגים |

## 2. שתי ההחלטות שהתקבלו

### 2.1 🔴 כתובת webhook אחת

**היום:** 4 שלוחות בימות, כל אחת עם כתובת.
**אחרי:** שלוחה **אחת** בימות → `/api/webhooks/yemot` → הכל רץ אצלנו.

```
בימות מגדירים פעם אחת:
   שלוחה 1 · type=api · https://chasamsofer.co.il/api/webhooks/yemot

ומשם הכל בשרת שלנו:
   ├─ 1 → חגים   → רישום · בחירת מוקד · שמיעת המוקד שנבחר
   ├─ 2 → יולדות → שיוך כרטיס מזון
   └─ 9 → הודעות
```

**למה זה עדיף:** כל שינוי בתפריט — סעיף חדש, שינוי סדר, פתיחה וסגירה של שירות —
נעשה אצלנו בלבד. אין `go_to_folder`, אין מספרי שלוחות לתחזק בשני מקומות.

⚠️ **חיוג ישיר ממשיך לעבוד.** ארבע הכתובות הקיימות נשארות חיות — מי שכבר
מוגדר בימות לא נשבר. הכתובת האחת היא *תוספת*, לא החלפה.

### 2.2 סעיף ראשי בתפריט הצד

יוצא מ**הגדרות** ועובר לתפריט הראשי, **מתחת לניוזלטר**:

```
שירותים
  ├─ הלוואות
  ├─ סיוע רפואי
  ├─ חלוקות חגים
  ├─ אלמנות ויתומים
  ├─ דוחות
  ├─ ניוזלטר
  └─ ☎️ מערכת טלפונית   ← חדש
```

## 3. המסך — `/admin/phone`

### 3.1 עץ השלוחות (מסך הבית)

```
┌─────────────────────────────────────────────────┐
│  ☎️ מערכת טלפונית          [🔗 כתובת ל-ימות]    │
├─────────────────────────────────────────────────┤
│                                                 │
│  📞 תפריט ראשי                    ● פעיל       │
│     "ברוכים הבאים להיכל החתם סופר"             │
│     ├─ 1 · 🎁 חגים               ● פעיל  4 הודעות│
│     │     ├─ רישום                              │
│     │     ├─ בחירת מוקד          18 ערים        │
│     │     └─ שמיעת המוקד שנבחר                  │
│     ├─ 2 · 👶 יולדות             ● פעיל  6 הודעות│
│     └─ 9 · 📢 הודעה כללית                       │
│                                                 │
│└─────────────────────────────────────────────────┘
```

לחיצה על שלוחה פותחת אותה. **מקור האמת הוא `lib/ivrMap`** — לא רשימה
מוקלדת ב‑JSX שמתיישנת בשקט.

### 3.1.1 🔴 שיחות יוצאות — אזור נפרד במסך

⚠️ **אלה אינן שלוחות ואינן בתפריט.** במסלולים האלה *אנחנו* מחייגים אל
המשפחה, ולא היא אלינו. הצגתן בתוך עץ התפריט הייתה מתארת מסלול שאיש אינו
עובר, ומי שיחפש שם "למה לא הגיע הקוד" לא ימצא דבר.

```
┌─────────────────────────────────────────────────┐
│  📤 שיחות יוצאות                                │
├─────────────────────────────────────────────────┤
│  🔑 קוד אימות לטלפון                            │
│     מופעל כשמבקשים קוד באזור האישי              │
│     תבנית: YEMOT_OTP_TEMPLATE_ID    ● מוגדר    │
│     ▶ האזן לנוסח                                │
│                                                 │
│  📢 הודעת אישור אחרי רישום                      │
│     צינתוק למי שנרשם ואושר                      │
│     תבנית: YEMOT_ANNOUNCE_TEMPLATE_ID ● מוגדר  │
│     ▶ האזן · [🎤 הקלט מחדש]                     │
└─────────────────────────────────────────────────┘
```

**ההבדל המהותי בין השניים:**

| | קוד אימות | הודעת אישור |
|---|---|---|
| מה נשמע | הקוד עצמו, מוקרא | הקלטה קבועה |
| מקור | `webhooks/yemot-otp` מקריא בזמן אמת | קובץ שהועלה מראש |
| ניתן לעריכה | ❌ הקוד נוצר לכל שיחה | ✅ טקסט + הקלטה |

⚠️ **ה‑OTP הוא שלוחה *וגם* שיחה יוצאת:** השיחה יוצאת מאיתנו, ואז ימות פונה
ל‑`/api/webhooks/yemot-otp` כדי לשאול מה להקריא. לכן הוא מופיע כאן ולא
בעץ — מבחינת המשתמש זו "שליחת קוד", לא שלוחה שמחייגים אליה.

### 3.2 מסך שלוחה — 3 לשוניות

**🎙️ הודעות** — הלב. כל הודעה בשורה משלה:

```
┌──────────────────────────────────────────────┐
│ ברכת פתיחה                          ▶ האזן  │
│ ┌──────────────────────────────────────────┐ │
│ │ ברוכים הבאים להיכל החתם סופר             │ │
│ └──────────────────────────────────────────┘ │
│ 🎵 greeting.wav · הוקלט 30.08    [🎤 הקלט]   │
└──────────────────────────────────────────────┘
```

- עריכת טקסט **והקלטה באותו מקום** — בלי לעבור מסך
- **▶ האזנה** לפני שמשפחות שומעות
- מצב ההקלטה גלוי: יש קובץ? מתי הוקלט? או "TTS בלבד"

**▶️ סימולטור** — לכל שלוחה, לא רק למוקדים. עובר את המסלול ומראה מה
המתקשר שומע בכל הקשה. רץ על `nextCenterStep` האמיתית ועל הנתונים האמיתיים.

**⚙️ הגדרות** — הכתובת להעתקה, משתני סביבה, ומה השלוחה עושה.

### 3.3 יומן שיחות

`YemotCallLog` הקיים, כלשונית.
