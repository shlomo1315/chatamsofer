# אפיון: תקלות משלוח — יריד הספרים

מוקאפ: `.hq-out/shipping-issues.html`

## מטרה
מקום אחד שבו מתעדים כל משלוח שדורש טיפול (לא הגיע, פגום, ספר לא נכון, חסר), עוקבים אחרי הטיפול עד הסוף, ומסננים כדי לראות מה עוד פתוח.

## משתמשים
צוות היריד באדמין (אותן הרשאות של מסך ההזמנות). אין חשיפה ללקוח בגרסה הזו.

## מיקום
- לשונית חדשה ב-`BookFairNav`: **"תקלות משלוח"** (אייקון `PackageX`), נתיב `/admin/book-fair/shipping-issues`, אחרי "זיכויים".
- בכרטיס ההזמנה (`orders/[id]`): סקשן **"תקלות משלוח"** עם כפתור "דווח על תקלה" ורשימת התקלות של ההזמנה.
- בטבלת ההזמנות: תגית כתומה "תקלה פתוחה" בשורה של הזמנה עם תקלה שלא טופלה.
- בסקירה (`/admin/book-fair`): מונה "X תקלות משלוח פתוחות" עם קישור למסך.

## סוגי תקלה (`type`)
| ערך | תווית |
|---|---|
| `not_arrived` | המשלוח לא הגיע |
| `damaged` | ספרים פגומים |
| `wrong_item` | נשלח ספר לא נכון |
| `missing_item` | חסר ספר בחבילה |
| `other` | אחר |

## סטטוסים (`status`)
| ערך | תווית | צבע |
|---|---|---|
| `open` | פתוח | אדום |
| `in_progress` | בטיפול | ענבר |
| `resolved` | טופל | ירוק |
| `cancelled` | בוטל (לא תקלה) | אפור |

`cancelled` מיועד לדיווח שנפתח בטעות, במקום מחיקה. אין מחיקה של תקלות.

## אופן הטיפול (`resolution`) — חובה במעבר ל"טופל"
| ערך | תווית |
|---|---|
| `resent` | נשלח משלוח חוזר |
| `replaced` | הוחלף הספר |
| `refunded` | זיכוי כספי |
| `arrived_late` | המשלוח הגיע בסוף |
| `no_action` | לא נדרשה פעולה |

"זיכוי כספי" מציג קישור למסך הזיכויים. הוא לא מבצע זיכוי בעצמו.

## שדות התקלה
| שדה | חובה | הערה |
|---|---|---|
| הזמנה (`order_id`) | כן | FK ל-`book_fair_orders`. נבחרת בחיפוש לפי מספר הזמנה / שם / טלפון, או אוטומטית כשפותחים מכרטיס ההזמנה |
| סוג תקלה | כן | |
| ספרים מושפעים | לא | בחירה מתוך פריטי ההזמנה + כמות. מוצג רק בסוגים `damaged`, `wrong_item`, `missing_item` |
| תיאור | כן | מה הלקוח דיווח. עד 2000 תווים |
| איך דווח | לא | טלפון / מייל / וואטסאפ / אחר |
| סטטוס | כן | ברירת מחדל `open` |
| אופן הטיפול | בטיפול=טופל | |
| הערות טיפול | לא | יומן: כל הערה נשמרת עם שם וזמן, לא שדה שנדרס |
| תאריכים | אוטומטי | `created_at`, `updated_at`, `resolved_at`, ו-`created_by` / `resolved_by` |

**יומן (timeline):** כל שינוי סטטוס נרשם ביומן אוטומטית ("שלמה שינה ל'בטיפול'"), לצד ההערות. מוצע לממש בטבלת אירועים נפרדת (`..._events`: issue_id, kind=`note`|`status`, text, from/to, by, at).

## המסך הראשי
**כותרת:** תקלות משלוח
**תת-כותרת:** משלוחים שדורשים טיפול — מהדיווח ועד הסגירה.
**כפתור ראשי:** + תקלה חדשה

**מסננים (שורה אחת, נשמרים ב-URL):**
1. צ'יפים של סטטוס עם מונים: **פתוחות** (= פתוח + בטיפול, ברירת מחדל) · פתוח · בטיפול · טופל · הכל. "בוטל" רק בתוך "הכל".
2. סוג תקלה (בחירה).
3. תאריך פתיחה: מ- / עד.
4. חיפוש: מספר הזמנה, שם לקוח או טלפון.
5. "נקה מסננים" מופיע רק כשיש מסנן פעיל.

**טבלה (מהחדש לישן, פתוחות ותיקות מודגשות):** מס' הזמנה (קישור להזמנה) · לקוח + טלפון · סוג · תיאור (שורה אחת, מקוצר) · סטטוס (תגית) · נפתח (תאריך + "לפני X ימים") · עודכן.
תקלה שפתוחה יותר מ-3 ימים: תגית קטנה "ממתינה X ימים".
לחיצה על שורה פותחת חלונית צד.

**חלונית צד (פרטי תקלה):** פרטי הזמנה וקישור אליה · סוג · ספרים מושפעים · תיאור · שינוי סטטוס בכפתורים (פתוח / בטיפול / טופל) · אופן הטיפול (נפתח כשבוחרים "טופל") · יומן + תיבת "הוסף הערה" · כפתורי "ערוך" ו"בטל תקלה".

## טקסטים
- כפתור יצירה: **+ תקלה חדשה** · בכרטיס הזמנה: **דווח על תקלה**
- כותרת דיאלוג: **תקלה חדשה במשלוח** · עריכה: **עריכת תקלה**
- placeholder תיאור: *מה הלקוח סיפר? לדוגמה: "הגיע 'שו"ת חתם סופר' חלק ב' במקום חלק ג'"*
- placeholder הערה: *מה נעשה? לדוגמה: "דיברתי עם השליח, יוצא משלוח חוזר מחר"*
- שמירה: **שמור תקלה** · ביטול: **ביטול**
- הודעות: "התקלה נשמרה" · "הסטטוס עודכן ל'בטיפול'" · "התקלה סומנה כטופלה" · "ההערה נוספה"
- שגיאות: "בחר הזמנה" · "בחר סוג תקלה" · "כתוב מה קרה" · "בחר איך טופלה התקלה"
- אישור ביטול: "לבטל את התקלה? היא תישאר בתיעוד בסטטוס 'בוטל'."
- מצב ריק (פתוחות): **אין תקלות פתוחות 🎉** / "כל המשלוחים בטיפול או טופלו."
- מצב ריק (מסנן): "לא נמצאו תקלות לפי הסינון." + "נקה מסננים"
- סקשן בכרטיס הזמנה, ריק: "אין תקלות במשלוח הזה."
- אזהרה בהזמנת איסוף עצמי: "ההזמנה הזו באיסוף עצמי, לא במשלוח. לתעד בכל זאת?"

## מצבי קצה
- כמה תקלות לאותה הזמנה — מותר (למשל פגום, ואחר כך המשלוח החוזר לא הגיע).
- פתיחה מחדש של "טופל" — מותרת, חוזר ל"פתוח", מנקה `resolved_at`, נרשם ביומן.
- הזמנה מבוטלת/מזוכה — מותר לתעד, מוצגת תגית סטטוס ההזמנה בחלונית.
- תקלה לא משנה את סטטוס ההזמנה ולא נוגעת במלאי.
- מובייל: הטבלה הופכת לכרטיסים, המסננים נגללים אופקית, החלונית במסך מלא.
